# Document Search Engine

A C++ document search engine that searches text files using an inverted index, Trie-based autocomplete, and TF-IDF ranking.

## Features
- Inverted index for efficient searching
- Trie-based autocomplete
- TF-IDF-based document ranking
- Priority queue for sorting search results
- Case-insensitive search
- Punctuation handling

## Technologies
- C++
- STL
- Data Structures and Algorithms

## How to Run

Compile:
```bash
g++ main.cpp -o DocumentSearchEngine -std=c++17
